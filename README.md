# 賽博龐克 2048 🎮

> 經典 2048 遊戲的賽博龐克風格重製版

## 遊戲玩法

- 使用方向鍵（或滑動）移動方塊
- 相同數字的方塊碰撞後會合併
- 目標：湊出 **2048** 方塊！

## 賽博龐克特色

- 🌃 暗黑賽博龐克主題配色
- 💜 霓虹紫/青色/粉色發光磁磚
- ✨ 炫酷合併動畫效果
- 📺 掃描線 CRT 視覺濾鏡
- 🔤 未來感字體設計
